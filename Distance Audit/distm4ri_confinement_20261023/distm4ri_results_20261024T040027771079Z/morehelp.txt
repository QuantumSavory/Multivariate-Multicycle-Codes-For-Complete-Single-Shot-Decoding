/home/fmian_umass_edu/distm4ri_tools/dist-m4ri/src/dist_m4ri (version 0.9.0): calculate distance of a classical or quantum CSS code
Usage: /home/fmian_umass_edu/distm4ri_tools/dist-m4ri/src/dist_m4ri method=[1|2|3] [parameter=value ...]

Required parameter:
  method=[int]       Bitmap / identifier for calculation method (no default):
                     1: Random Window (RW) algorithm (upper bound)
                        Finds an upper bound on distance by testing random
                        information sets. Fast for finding small codewords.
                     2: Connected Cluster (CC) algorithm (lower bound / exact)
                        Exhaustive cluster search finding a lower bound or exact
                        minimum distance. Guaranteed to find the true code
                        distance if run to completion.
                     3: Bracketing mode (concurrent RW and CC)
                        Dynamically balances CC (lower bound) and RW (upper
                        bound) worker threads based on distance estimate (dexp),
                        current bounds [dmin, dmax], and remaining timeout.

Input matrices and code specification:
  finH=[file]        Parity check matrix H (for classical codes) or Hx (for
                     quantum CSS codes) in Matrix Market (.mmx / .mtx) format.
  finG=[file]        Generator / Hz matrix for quantum CSS codes in Matrix Market
                     format. Used to verify orthogonality and construct logicals.
  finL=[file]        Logical operator matrix Lx for quantum CSS codes in Matrix
                     Market format.
                     Note: For a quantum CSS code, either finL (Lx) or finG (Hz)
                     must be provided.
  fin=[str]          Base name for matrix input files (default: "try").
                     Automatically looks for "${fin}X.mtx" as finH and
                     "${fin}Z.mtx" as finG.
  fdem=[file]        Detector Error Model file (.dem) generated by Stim.
                     Automatically constructs H and L matrices. Cannot be
                     combined with finH, finG, finL, or fin.
  pmin=[float]       Minimum error probability threshold for DEM parsing (0.0).
                     Error mechanisms with probability < pmin are ignored.
                     Only valid when fdem is specified.
  classical=[0|1]    Code type override:
                     1: Treat as a classical linear code (Hx only; ignores
                        or discards logical matrix L).
                     0: Treat as a quantum CSS code (requires L or G matrix).
                     Default: 1 if only finH is given; 0 if finG, finL, fin,
                     or fdem is provided.
  css=[int]          Reserved for future non-CSS quantum code support (1).

Distance bounds and search guidance:
  dmin=[int]         Known certified lower bound on distance (default: 1).
                     In CC (method 2/3), cluster search begins at w = dmin.
  dmax=[int]         Known upper bound on distance (default: 0).
                     In RW (method 1/3), codewords of weight >= dmax are ignored
                     unless collecting codewords.
  dexp=[int]         Expected code distance (alias: dest) (default: 0).
                     Used in method=3 (bracketing) to balance worker threads
                     between CC and RW and estimate search feasibility.

Search limits and Connected Cluster (CC) options:
  steps=[int]        Maximum number of RW decoding steps / information sets
                     (default: 1000). Ignored in method=2.
  wmin=[int]         Minimum distance threshold (default: 1).
                     If a codeword of weight w <= wmin is found, execution
                     terminates immediately. Useful for screening codes.
  wmax=[int]         Maximum cluster weight to analyze in CC (default: 0).
                     In method=2, CC terminates after checking weight wmax.
                     0 means continue until codeword found, bounds meet, or timeout.
  smax=[int]         Maximum syndrome weight for confinement profile (default: 5).
                     When smax > 0, tracks minimum syndrome weights for each
                     error weight. Set smax=0 to disable confinement calculation.
  noscan=[0|1]       1: Start CC directly at weight wmax, skipping scan over
                     weights w < wmax (default: 0). Only valid for method=2.
  start=[int]        Restrict CC search to start column index (default: -1).
                     Equivalent to setting cbeg=start cend=start.
  cbeg=[int]         Beginning column index for CC search (default: -1, start at 0).
  cend=[int]         Ending column index for CC search (default: -1, end at n-1).

Codeword collection and export:
  outC=[file]        Export found codewords to file in .nz list format.
  finC=[file]        Import initial candidate codewords from file in .nz format.
  maxC=[int]         Maximum number of codewords to collect (default: 0).
                     0 means collect all valid codewords found up to wmax or stop
                     flag. If maxC > 0, halts when maxC codewords are collected.
  dW=[int]           Extra weight window above minimum distance (default: 0).
                     Collects codewords with weight up to min_w + dW.

Execution, multithreading, and timing:
  threads=[int]      Maximum number of worker threads to use (default: 0 =
                     hardware concurrency). Subject to throttling for small
                     codes or large matrices unless nothrottle=1 is set.
  timeout=[sec]      Execution timeout in seconds (default: 60.0, 0 = infinite).
                     In method=3, dynamically guides CC vs RW thread balance.
  nothrottle=[0|1]   Disable automatic thread throttling (default: 0).
                     Aliases: --no-throttle, -no-throttle, nothrottle.
                     By default, threads are throttled for very small codes or
                     large matrices to avoid cache and memory bus thrashing.
  chunk_size=[int]   RW batch chunk size per worker (default: 0 = adaptive).
                     Alias: batch=[int].
  seed=[int]         Random number generator seed (default: 0 = initialize from
                     current time).

Debug output bitmap (debug=[int], default: 3):
  The debug parameter accepts a bitmask controlling diagnostic output to stderr:
    0    : Clear entire debug bitmap (completely silent execution)
    1    : General progress and round summary information (on by default)
    2    : Detailed thread allocation and timing information (on by default)
    4    : Command-line argument parsing diagnostics
    8    : Progress reports every 1000 RW steps
    16   : Output new minimum-weight codewords as they are found
    32   : Dump matrices and full codeword lists
    64   : Debug confinement hash table updates (swei changes)
    128  : Debug duplicate syndromes in confinement hash (debug build)
    2048 : Allow large matrix and vector output (bypasses size cutoff)
  Multiple debug arguments are XOR-combined (except debug=0 which clears all).
  Tip: Place debug=0 as the first argument to silence all diagnostic output.

Output format (stdout):
  Standard output produces a single line with three space-separated integers:
    dmin dmax rw_steps
  where:
    dmin-1   : Maximum cluster weight analyzed by CC without finding any codeword.
               If CC finds an exact minimum-weight codeword, dmin = dmax = weight.
    dmax     : Smallest weight of any codeword found (0 if no codeword found).
    rw_steps : Number of completed RW steps (0 if CC found exact or method=2).
